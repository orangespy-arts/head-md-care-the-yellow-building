# README Unity projects

## DevYellowBuilding

This project is the main project used for development of the yellow building. It contains all the assets, scripts, and scenes related to the yellow building and the full history of the project. It is not the latest version as the repository was growing too large. 

## YellowBuilding final version

The final version is in a separate repository. It contains only the latest version of the project, with all the assets and scripts needed to run the yellow building. It is a clean version of the project, without any of the history or unused assets. It is the version that should be used for any future development or deployment of the yellow building.
